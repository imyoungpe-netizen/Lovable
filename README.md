# DARK ACE — фронтенд для Lovable

Здесь находится отдельная копия интерфейса DARK ACE, подготовленная для продолжения работы в Lovable. Игровой API, Telegram-боты, фоновые процессы и база данных остаются на Render.

## Подключение

1. Импортируйте папку `lovable-export` в отдельный GitHub-репозиторий и подключите этот репозиторий в Lovable. Не переносите в него серверную часть или секреты.
2. Установите переменную сборки `VITE_DARK_ACE_API_URL` в значение `https://dark-ace-game.onrender.com`.
3. Для локальной проверки скопируйте `.env.example` в `.env`, затем выполните `npm install` и `npm run dev`.
4. Перед рабочим запуском внесите точный origin Lovable-приложения в разрешённые origins Render через переменную `DARK_ACE_APP_ORIGIN`. Сервер намеренно не принимает запросы с произвольных сайтов.

## Важно

- Вход работает только внутри Telegram Mini App: обычное открытие сайта не передаёт проверенные Telegram-данные.
- В браузерной сборке нет секретных ключей и доступа к базе напрямую.
- Перед переключением пользователей проверьте вход, запросы API, WebSocket, ставки и профиль на отдельном адресе. Пока origin Lovable не добавлен в Render, межсайтовые API-запросы и WebSocket будут отклоняться.
- Это копия для подготовки интерфейса; изменения здесь не меняют автоматически рабочее приложение.
